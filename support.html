技术支持Support

遇到安装、激活或使用问题，请邮件联系：support@resmodel.com（2 个工作日内回复）。 For installation, activation or usage problems, email support@resmodel.com — we reply within 2 business days.

常见问题Common issues

macOS 提示“无法验证开发者”：在 Finder 中右键点击应用 → 选择“打开”；或到 系统设置 → 隐私与安全性 → 仍要打开。 macOS says the developer cannot be verified: right-click the app in Finder → Open; or go to System Settings → Privacy & Security → Open Anyway.

Windows SmartScreen 拦截：点击“更多信息” → “仍要运行”。 Windows SmartScreen blocks the app: click “More info” → “Run anyway”.

Windows 提示缺少 WebView2：安装 Microsoft Edge WebView2 Runtime（Windows 11 已内置）。 Windows reports WebView2 is missing: install the Microsoft Edge WebView2 Runtime (built into Windows 11).

更换电脑：请邮件说明旧设备与新设备，我们协助迁移许可证。 Moving to a new computer: email us the old and new device details and we will help transfer the licence.
